# Lint Wiki

Use when the user says:

- "Lint the wiki"
- "Health-check the wiki"
- "Check source tracking"
- "Check privacy risks"
- "Find gaps"

## Command

Read `AGENTS.md`, `MEMORY.md`, `INDEX.md`, `LOG.md`, and `wiki/workflows/lint_wiki.md`.

Check source tracking, privacy and security risks, evidence labels, conceptual consistency, knowledge ownership boundaries, overlapping concepts, orphan pages, stale overview/synthesis/domain-map/reference-plan/workflow/index/memory entries, and future RAG readiness.

Report findings first, ordered by severity.

Fix only what the user asked to fix unless the user explicitly authorizes fixes.
