# Ask Wiki

Use when the user asks a question against the research wiki.

## Command

Read `AGENTS.md`, `MEMORY.md`, `INDEX.md`, and `wiki/workflows/query_wiki.md`.

Find and read relevant wiki pages.

Answer with clear separation between:

- Evidence-backed claims.
- Interpretation.
- Research gaps.
- Speculative design direction.
- Privacy/security considerations.
- Clinical decision boundaries.

If the answer creates durable synthesis, ask whether to save it back into the wiki unless the user already requested that.
