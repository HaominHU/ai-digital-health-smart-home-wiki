# Generate Design or Spec Prompt

Use when the user asks for a prompt for:

- System design.
- Product design.
- Smart home or digital health prototype design.
- Coding plan mode.
- Research prototype specification.
- Study or evaluation planning.

## Command

Read `AGENTS.md`, `MEMORY.md`, `INDEX.md`, and `wiki/workflows/generate_design_spec_prompt.md`.

Use relevant wiki pages to generate an AI-ready prompt.

Include intended use, non-use, stakeholders, caregiver and care recipient needs, condition overlays, technology lens, evidence-backed requirements, gaps, assumptions, privacy/security constraints, human oversight, and clinical decision boundaries.

Save under `outputs/design_prompts/` or `outputs/spec_prompts/` if the user asks for a durable file.
