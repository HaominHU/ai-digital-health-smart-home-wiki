# Generate Research Prompt

Use when the user asks for a prompt for:

- Research writing.
- Literature synthesis.
- Study framing.
- Manuscript drafting.
- Proposal or grant brainstorming.
- Agent plan mode for research work.

## Command

Read `AGENTS.md`, `MEMORY.md`, `INDEX.md`, and `wiki/workflows/generate_research_prompt.md`.

Use relevant wiki pages to generate an evidence-aware prompt.

Include source-grounded context, evidence gaps, caregiver vs care recipient distinctions, condition/aging/disability cautions, privacy/security constraints, and the clinical decision boundary.

Save under `outputs/research_prompts/` if the user asks for a durable file.
