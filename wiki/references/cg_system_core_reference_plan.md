# Caregiver System Core Reference Plan

## Purpose

This file tracks the intended core reference backbone for the caregiver system-design wiki lane. It is a planning and status file, not a citation-memory item and not source-backed wiki evidence by itself.

Use it to connect staged ingest batches, source numbers, missing-source decisions, and each source's intended writing role. Create or update canonical citation-memory records under `wiki/references/items/` only after a source is previewed and integrated.

## Status Legend

- `integrated`: Evidence page and citation-memory item exist.
- `planned`: Local source is available or expected for future preview-first ingest.
- `skipped_for_now`: Intentionally not included in the immediate ingest batch.
- `future`: Important core source family, but not currently in this staged batch.

## Ingest Batch Connection

- Initial and early core sources: Hu abstract/dissertation, Setiawan 2019, Schulz/Sherwood, Schulz 2020, NASEM 2016, Van Houtven 2011, Mohammed 2023, Hartnett 2016, Glasgow 2001, Lewis 2020, Yao 2023, and CareBuddy sources are already integrated where applicable.
- Part 3 included stress-process and broad digital caregiver intervention sources such as Aneshensel/Avison 2015, Schulz/Sherwood 2008, Graven 2021, and Zhai 2023.
- Part 4 closed the first dementia intervention block with REACH II/REACH VA, COPE, Savvy Caregiver, Tele-Savvy, and Walter/Pinquart 2020.
- Part 5 closed the narrowed dementia caregiver block with Cheng 2020, Bressan 2020, and Ruggiano 2021. AHRQ 2020 remains a future potential reference but is skipped for now because the report is too long for the current staged ingest.

## Numbering Model

The updated core list uses base source numbers through `29`, with additional or supporting already-ingested sources kept at `30+` rather than deleted from the wiki.

- `01` and `02` are reserved for future foundational theory sources: Pearlin et al. and Lazarus/Folkman.
- `03` through `15` cover the current foundational, broad digital caregiver support, and narrowed dementia/ADRD Tier 1 branch.
- The gap between `15` and `19` is intentional in the current folder/list.
- `19` begins the SCI caregiver branch.
- `26` is the currently integrated gynecologic cancer caregiver source.
- `29a`, `29b`, and `29c` are the grouped AI-agent architecture and evaluation support set.
- `30+` holds already-ingested or supporting sources that remain useful but are no longer Tier 1 base-list items.
